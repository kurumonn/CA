# Atlas asset generation source

`base_assets.py` is the original procedural source of the split Atlas assets supplied earlier in this project. `../build_atlas.py` applies a restrained detail pass and generates 40 asset types at two levels of detail. Generated assets are explanatory exhibition objects, not operational security devices.

The textures are procedurally generated by this source. No external photographs or font files are included. Runtime Three.js code is covered by the existing `viz/vendor/three/LICENSE`.

Use `python tools/build_atlas.py` from the repository root. Do not invoke the original base source's historical scene builder as the integration entry point.
