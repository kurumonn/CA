# 05 3D 学習空間の設計 — 信頼のアトリエ

実装: `viz/`（three.js r169 を同梱。CDN なしで動作）

## 1. 方針

- 「CA が発行する判断」と「利用者が信頼する判断」を**別の場所**に置く。
- 秘密鍵（金の鍵）は象徴であり、どの場面でも移動しない（`viz/tests/lesson.test.mjs` で検査）。
- ルート証明書はサーバーから届かない。利用者が別経路で信頼ストアに入れる。
- 押印は電子署名のたとえ。「証明書を暗号化する」とは説明しない。
- 検証ゲートは端末内部の確認を拡大した比喩。並び順は実装の実行順とは限らない。
- 再生は**説明用シミュレーション**。ラボの実測は `export-events` の JSON を読み込んで区別して表示する。
  `measured === true`（真偽値）かつ `origin === "measured"` の記録だけを「実測」とし、ファイルの真正性はブラウザでは検証していないと明示する。検証・TLS は処理全体の結果（集約）しか記録していないので、段階ごとの実測としては表示しない。
- カード・CRL ボード・信頼ストア・接続先の表示は `lesson.js` の `scenarioView()` から作り、説明文（`captionFor()`）と同じデータで更新する。条件を変えるとカードの EKU・CRL の発行者と失効項目・基準時刻・信頼ストアの内容が切り替わる。

## 2. 空間構成（28m × 20m、屋根なし展示施設）

```
                    発行・運用側（奥）
 ルートCA室 ── 中間CA室 ─ 監査 ── サーバー ── 失効情報(CRL)
  (-11,-6)      (-5,-6)   (-2.2,-8.4) (2,-6)     (9,-6)
                                                        OCSP 比較 (12.4,0.5)
   RA 申請窓口         利用者端末＋信頼ストア
    (-8,4.5)            (0.8,5) (-1.6,6.6)
                                 └→ 検証ゲート①〜⑥ (4.6〜11.6, 5) → 出口
                    利用側（手前）            入口フレーム (0,9.6)
```

座標の正本は `viz/js/lesson.js` の `STATIONS`。

## 5. 比較条件（9種）

| 条件 | 止まるゲート | 結果コード | 判定 |
|---|---|---|---|
| 本編 | 最後の新規接続で⑤ | `LEAF_REVOKED` | REJECT |
| 正常 | なし | `OK` | ACCEPT |
| 信頼していないルート | ① | `UNTRUSTED_ANCHOR` | REJECT |
| 名前が違う | ② | `SAN_MISMATCH` | REJECT |
| 期限切れ | ③ | `CERT_EXPIRED` | REJECT |
| 用途違い | ④ | `WRONG_EKU` | REJECT |
| 葉が失効 | ⑤ | `LEAF_REVOKED` | REJECT |
| 中間CAが失効 | ⑤（中間カードが赤） | `INTERMEDIATE_REVOKED` | REJECT |
| CRL が古い | ⑤（橙） | `CRL_EXPIRED` | INDETERMINATE |

結果コードは `pkilab.py verify / client` と同じ。

## 7. 位置づけと既知の制約

この 3D は**コード生成による軽量教材モード**（教材プロトタイプ）である。以前に依頼された「分割 GLB・LOD・AAA 品質のモデル群」の納品・統合ではない（要件未達）。

| 評価対象 | 現状 |
|---|---|
| 発行・検証・失効を動かして説明する教材 | 実装あり。条件と表示内容の整合は試験済み |
| 以前の分割 GLB・LOD・アニメーションの統合 | 未実施。元アセットがこのリポジトリと作業環境に無い |
| AAA 品質のモデル・材質 | 要件未達（固有 UV・ベイク・LOD・KTX2 なし。プリミティブと Canvas ラベル） |
| 実機での負荷・FPS | 未測定 |

GLB を統合する場合は、モデル ID・寸法・材質・可動部・LOD・衝突形状・ライセンスを対応付けたマニフェストを別途作り、コード生成版は軽量モードとして残す。GLB に変換する・ポリゴン数を増やすだけでは AAA 品質にはならない。

- 全体表示で約11万三角形・約600 draw call は、作者環境の Chromium / SwiftShader で `renderer.info` から読んだ値で、独立した測定ではない。
- 日本語ラベルは閲覧環境のフォントで描く。
